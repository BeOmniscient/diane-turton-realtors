# Diane Turton, Realtors — Growth OS

Private strategy package for Diane Turton, Realtors. Powered by Omniscient.

## Contents

| File | Purpose |
|---|---|
| `pitch-deck.html` | Interactive 9-slide leadership pitch deck (single-file, responsive, print-ready) |
| `intelligence-dashboard.html` | Interactive intelligence website with company analysis, agent visualization, and lost-revenue calculator |
| `pilot-program.md` | 90-day pilot program plan: phases, KPIs, rollout, agent onboarding |
| `system-architecture.md` | Layered architecture overview, data model, integration map |
| `ghl-workflows.md` | GoHighLevel funnels, automations, SMS/email templates, pipeline stages |
| `ai-voice-prompts.md` | Retell AI prompts, conversation flows, edge cases, escalation logic |
| `m/` | Phone edition: one mobile hub with the pitch, revenue calculator, digital report card, and all four docs as readable pages. Phones visiting `/` are sent here automatically (`/?desktop` opts out). |

## Viewing the HTML files

Both HTML files are self-contained. Open directly in any modern browser:

```bash
open pitch-deck.html
open intelligence-dashboard.html
```

The pitch deck supports keyboard navigation (← → arrows, Space, Home/End), swipe on touch devices, and prints cleanly to PDF (one slide per page).
